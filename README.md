# Battalion Metals website

Responsive single-page precious-metals storefront concept.

## Preview locally
Open `index.html` in a browser. No build step is required.

## Deploy
This is a static site and can be hosted with GitHub Pages, Netlify, Cloudflare Pages, or another static host.

## Before going live
- Confirm the legal right to use the Battalion Metals name, logo, and brand assets.
- Replace illustrative product examples with verified product data, inventory, prices, terms, and business contact details.
- Connect a trusted spot-price data provider if showing live quotes.
- Connect a secure backend, checkout/payment processor, tax/shipping logic, and order notifications.
- Connect the contact form to a form provider or backend endpoint.
- Add privacy policy, terms, shipping/returns, and required regulatory disclosures.
- Confirm all claims and legal requirements with qualified counsel. Do not publish placeholder claims or prices as factual.

This is a front-end demo. Bag interactions work locally, but it does not accept payments or submit messages.
